# Submission checklist

**Submit by 4:30pm CDT Thu Oct 15.** The hard deadline is 5:30pm. Leave the last hour for upload problems.

## Project and safety

- [ ] Repository is public and the link opens without signing in.
- [ ] README placeholders are filled: problem, solution, setup, run steps, and working links.
- [ ] `.env.example` is present and documents required variables.
- [ ] No API keys, tokens, private data, or local `.env` files are committed.
- [ ] CI is green on the submission commit, including lint, typecheck, and build.
- [ ] Deployed URL opens in an incognito window and the rehearsed demo path works.
- [ ] The challenge we picked is stated in the README and in the submission form.

## Submission assets

- [ ] Demo video is recorded, accessible, and within the event time limit.
- [ ] Screenshots show the key workflow and are linked or uploaded where requested.
- [ ] Team names and roles are accurate in the README and submission form.
- [ ] Dataset names, source URLs, and required credits or licenses are included.
- [ ] Submission form fields are complete: project name, short description, repo URL, deployed URL, video URL, team, and relevant category.
- [ ] Every submitted link is tested in a private browser window.

## Final run

- [ ] Three-minute demo is rehearsed with a timer and exact prompts.
- [ ] `DEMO_CACHE=1` fallback is warmed and verified, and backup video or screenshots are ready.
- [ ] A teammate has reviewed the final submission before the deadline.
